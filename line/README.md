# 報平安官方帳號 × 防詐查證

「報平安」LINE 官方帳號除了家人報平安，也能直接查詐騙。後端在 arcar Worker（v21 起）的 `/safe/webhook`。

## 長輩怎麼用
- **查可疑訊息**：長按簡訊或 LINE 訊息 →「轉傳」給報平安，或直接傳截圖 → 回覆紅／黃／綠判斷卡片（撥打 165、轉給家人看）
- **查電話**：傳電話號碼 → 先判斷號碼（+886、國外來電）→ 點「對方說了什麼」快選 → AI 綜合判斷
- 指令：`查訊息`、`查電話`、`防詐小知識`、`我要報警`；原有的 `平安 123456`、`取消平安 123456`、`平安狀態` 照舊（平安狀態改用打字查詢）

## 規則
- 全部用 reply 回覆，不吃每月推播額度
- 只處理一對一聊天；帳號被拉進群組時不會回應一般訊息
- 每人每天最多查 30 次（KV `scamq:{uid}:{date}`）；查號碼後 10 分鐘內的下一則訊息當作「對方說的內容」（KV `scamtel:{uid}`）
- AI 失敗時回「無法確定」並建議打 165

## 圖文選單（2 列 × 3 格）
查可疑訊息｜查電話｜撥打 165
我要報警（回覆卡片：撥 110、附近警察局、撥 165；arcar v22 起）｜推薦防詐（推薦官方帳號給親友）｜防詐 App
